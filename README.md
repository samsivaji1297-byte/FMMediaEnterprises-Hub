# FM Media Enterprises

A sovereign, automated, compounding media organism designed to compete with
Bloomberg, BuzzFeed, Vice, Vox, Morning Brew, and every modern media house.

This repo contains:

- FM Core Identity Engine
- FM Content Engine
- FM Automation Engine (Gemini + GitHub Actions)
- FM Visual Identity System
- FM Widgets for home-screen access

This is the foundation layer. Expansion comes next.

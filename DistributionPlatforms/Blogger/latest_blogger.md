## Step‑By‑Step Execution Protocol  

1. **Clarify the Desired Outcome** – Write a single sentence of the exact result you need (e.g., “capture daily tasks in one view”).  
2. **List All Candidates** – Pull every app you’re considering into a column.  
3. **Score Fast** – 0 = doesn’t meet outcome, 1 = partial, 2 = full match.  
4. **Trim to ≤3** – Keep only those with a score of 2.  
5. **Set a 15‑Minute Timer** – When it rings, install the top scorer and archive the rest.  
6. **Lock‑In & Iterate** – Use the chosen tool for 30 days; if it fails, repeat the sprint with a new shortlist.
